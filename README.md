1. Clone this repository: https://github.com/palasja/RSS_Node_CRUD_API
2. Go to folder `RSS_Node_CRUD_API`  
3. To install all dependencies use [`npm install`](https://docs.npmjs.com/cli/install)  
4. Run **test** in command line for running tests
5. Run **start:dev** in command line for running development mode
6. Run **start:prod** in command line for running production mode
